# 오늘의 성구 위젯

wol.jw.org의 '날마다 성경을 검토함' 오늘 성구와 본문을 안드로이드 홈 화면에 보여 주는 위젯입니다.

## 설치
휴대폰에서 아래 주소를 열어 APK를 내려받아 설치합니다.

`https://github.com/<사용자>/<저장소>/releases/latest/download/daily-text-widget.apk`

처음 설치할 때 '출처를 알 수 없는 앱 설치'를 허용해야 합니다.

## 사용
- 홈 화면 빈 곳을 길게 누르고 **위젯 → 오늘의 성구**를 놓습니다.
- 본문은 위젯 안에서 위아래로 스크롤됩니다.
- ↻: 새로 고침 / 날짜나 본문을 누르면 원문 페이지가 열립니다.
- 자정 직후와 3시간마다 자동으로 갱신됩니다.

## 빌드
`main` 브랜치에 push하면 GitHub Actions가 APK를 만들어 Releases에 올립니다.
